## Casos Destacados

### 1. Performance Executive

CRM para equipos comerciales con enfoque en analitica y control de costos.

- Problema: alto gasto en infraestructura y baja visibilidad de rendimiento comercial.
- Solucion: arquitectura optimizada en Firebase con cache inteligente, control de consultas y paneles en tiempo real.
- Resultado: 99.1% de reduccion de costos y operacion estable para 50-100 usuarios concurrentes.

Enlaces:

- Repositorio: https://github.com/TeamInfinixdevcom/performandeexecutive
- Demo: https://executiveperformancek.web.app/login

### 2. Kolbi Monitor Web

Plataforma de inventario y ventas en tiempo real para operacion multi-rol.

- Problema: tiempos altos en flujo de solicitudes y poca trazabilidad operativa.
- Solucion: sistema React + Firebase con sincronizacion en vivo, dashboards y generacion de reportes.
- Resultado: 70% de mejora en procesamiento y visibilidad instantanea de inventario.

Enlaces:

- Repositorio: https://github.com/TeamInfinixdevcom/kolbi-monitor-web
- Demo: https://kolbimonitorsells-infinix.web.app/

### 3. InfiniHR Web

Sistema de gestion de recursos humanos para procesos empresariales completos.

- Problema: procesos de RRHH dispersos y poca estandarizacion de controles.
- Solucion: plataforma con control de accesos por roles, gestion de ciclo de empleado y reporteria.
- Resultado: digitalizacion centralizada y base escalable para crecimiento organizacional.

Enlaces:

- Repositorio frontend: https://github.com/TeamInfinixdevcom/infinihr-web
- Repositorio backend: https://github.com/TeamInfinixdevcom/InfiniHR
